# Pattern 10 · 暗誦英文

用 10 個高品質英文句型，把「看得懂」練成「說得出」，再練到能用在沒背過的新句子上。每天約 5 分鐘。

**直接玩：** https://kinnsou.github.io/temporary/pattern10/

- 手機：用 Chrome 或 Safari 打開，選「加入主畫面」，就能像 App 一樣用，也能離線。
- 語音作答：請用 Chrome 或 Edge（需要連網，本程式不保存錄音）。

## 你的進度存在哪裡？

只存在**你自己這台裝置、這個瀏覽器**裡，不會上傳到任何伺服器，作者也看不到。

- 換手機或電腦：到「設定 → 匯出備份」，在新裝置「匯入備份」。
- 清除瀏覽器資料，進度也會一起不見。程式另外在瀏覽器裡多存了一份鏡像，被同網域其他網頁誤清時會自動還原，但仍建議定期備份（超過兩週沒備份，首頁會提醒）。
- iPhone／iPad：請「加入主畫面」，否則 Safari 可能在 7 天沒開之後清掉網頁資料。
